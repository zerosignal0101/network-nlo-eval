# H3 前向泵核/剖面拟合审计

日期：2026-11-04
工作树：`wt/h3-forward-audit`（分支 `feat/h3-forward-audit`，基线 `c69ba98`）

## 1. 结论摘要

问题：同一耦合 ODE 剖面下，`pcfm_h3_raman` 相对 `hybrid_raman_paper`
前向泵偏乐观 0.1–0.3 dB，是否因为剖面峰值被三次多项式平滑掉？

结论：**不是**。审计给出三条可复现的结论（单跨 100 km、50 GBd、1 mW/pol）：

1. **多项式拟合的贡献 ≤ 0.08 dB，前向 3ch 只有 0.02 dB。**
   `poly_degree=3, spp_steps=12` 相对收敛解 `(9, 96)` 的 SNR 差为
   −0.020 dB（3ch 前向）、−0.025 dB（5ch 前向）；全场景最大 0.082 dB
   （5ch 后向）。前向场景下符号还让 H3 略**悲观**。
2. **0.3 dB 的差主要来自 H3 默认的 EGN 修正，而不是核或拟合。**
   EGN 对 SNR 的贡献是 +0.40…+0.73 dB（1ch 为 +0.73，5ch 前向为
   +0.44）。关掉 EGN 后 H3 反而比 hybrid 悲观 0.10–0.24 dB。
3. **前向泵没有额外放大差距。** 用“同配置 − 无泵配置”的差：
   前向为 −0.02…−0.05 dB（即差距不比无泵更大），后向为 −0.08…−0.10 dB。
   0.3 dB 的差在无泵时同样存在（3ch 无泵 0.361 dB）。

更强的对照：把 hybrid 切到它保留的旧 PCFM 核路径
（`nli_form="pcfm"`, `poly_degree=3`, `spp_steps=12`, `egn=True`），
它与 H3 共用同一套 SCI/XCI 代码和 EGN，只差剖面提供者。此时
H3 − hybrid_pcfm 只有 **−0.046 dB**（前向，来自 ODE 步数 24 vs 12），
无泵/后向为 **0.000 dB**（逐位相同）。也就是说 H3 的剖面注入路径没有
引入任何额外偏差。

因此本 WP **不修改任何默认**：拟合误差界远小于模型的其他已知误差项
（见 §5、§6），改默认只会移动一个非主导项，还会破坏无泵逐位一致。

## 2. 场景与方法

固定参数（与 `scripts/dra_waveform_compare.py` 一致）：

| 项 | 值 |
|---|---|
| 光纤 | 100 km，0.2 dB/km，D=15.6808 ps/nm/km，S=0.04124 ps/nm²/km，A_eff=80 µm²，n2=2.6e-20 m²/W |
| 栅格 | FlexibleGrid 12.5 GHz，100 GHz 间隔、50 GHz 占用 |
| 信道 | 1 / 3 / 5 |
| 符号率 | 50 GBd，QPSK，roll-off 0 |
| 发射功率 | 1 mW/pol（0 dBm） |
| 泵浦 | 1450 nm、0.2 W、前向或后向、0.25 dB/km；对照为无泵 |
| 跨数 | 1 |
| EDFA | NF = 5.5 dB |

审计脚本 `scripts/h3_forward_audit.py` 对每个场景：

1. 用与 `PCFH3RamanSpanKernel._solver_for` 相同的参数重建**原始**
   `profile_norm`（泵浦时为 `RamanPaperSpanSolver` 的耦合 ODE 解；
   无泵时为父类 ISRS 解），位置为每步中点/终点，即 `u = i/N`。
2. 调 `spp_samples` / `profile_polynomial` / `sci_kernel` / `xci_kernel`
   得到多项式表示，并与原始剖面比较：
   - 逐点相对残差（含 `u=0` 外推点）、中位残差；
   - `∫p² du` 相对误差（XCI 核只用到这一项）；
   - SCI 核相对**直接二维积分**的误差：
     `K_SCI = ∫∫ p(z)p(z') Q(z-z') dz dz'`，
     `Q(d) = 4 Si(λd)/(c d)`，`λ = π²β2,eff B²`，`c = 4π²β2,eff`。
     该积分与多项式核在 `(9,96)` 下吻合到 1e-4，可作无拟合基准。
3. 检查 `_resample_profile`：与同一线性插值逐位比较。
4. 扫 `poly_degree ∈ {3,5,7,9}` × `spp_steps ∈ {12,24,48,96}`。
5. 扫 `raman_steps ∈ {12,24,48,96}`（固定 `(9,96)`），隔离粗 ODE 误差。
6. 逐项比较 H3 / `hybrid_raman_paper(nli_form="paper")` /
   `hybrid_raman_paper(nli_form="integral")` / 同核对照 `hybrid_pcfm`。

输出：`results/raman/h3_forward_audit.json`。

### 2.1 取数口径

- SNR 为 **NLI-limited**：`10 log10(P_signal / (P_SPM + P_XPM))`，逐信道
  后取算术平均，与 `dra_waveform_compare.py` 一致。
- H3 用默认配置：`poly_degree=3, egn=True, edge_fix=True,
  spp_steps="auto"`。1 mW 下 `spp_steps` 解析为 12；前向泵的
  `raman_steps` 解析为 24，无泵/后向为 12。
- 单跨时 `span_coherence` 的 `auto` 解析结果不影响结果（无跨间求和）。

## 4. 拟合误差：逐点大、积分小

3ch 默认 `(3,12)` 的拟合残差（内部顺序 → 模型顺序已转换）：

| 场景 | 逐点最大相对误差 | 逐点中位 | `u=0` 外推 | `∫p²` 相对误差 | `K_SCI` 相对误差 |
|---|---:|---:|---:|---:|---:|
| 3ch 无泵 | 225% | 8.0% | +5.1% | −3.2% | −0.25% |
| 3ch 前向 | 239% | 12.8% | +37.5% | +0.40…+0.51% | +0.42…+0.46% |
| 3ch 后向 | 35% | 6.8% | +5.6% | −3.5% | −0.17% |

逐点残差很大，是因为三次多项式无法表示跨首的陡峭峰/指数衰减；
`u=0` 更是纯外推（拟合采样从 `0.5/N` 开始）。但 PCFM 只通过
`∫p²` 与 SCI 岛积分使用剖面，二者都远好于逐点误差
（`xci_kernel` 的误差与 `∫p²` 列完全一致，因为 XCI 核只差一个
与信道无关的常数矩阵；JSON 里单列为 `xci_kernel_max_rel_error`）：

- 前向剖面的峰在 `u≈0.19`，形状宽，三次拟合的积分误差只有 0.4–0.5%；
- 无泵/后向剖面接近 `exp(−αLu)`，三次拟合的 `∫p²` 偏低 3.2–3.5%，
  拉低 XPM；但 XPM 在 3/5ch 里比 SPM 低 2–4 dB，折算到 SNR 只有
  0.04–0.08 dB；
- `(9,96)` 时 `K_SCI` 与直接二维积分吻合到 1.2e-4，说明基准本身可靠。

结论：把“逐点拟合误差大”当成 NLI 偏乐观的证据是不成立的；正确的
度量是核积分误差。

`_resample_profile` 本身没有引入误差：它与同一线性插值逐位相同
（最大绝对差 4.4e-16）。前向泵下 `raman_steps=24 → spp_steps=12`
是**精确隔点抽样**（目标网格是源网格的子集），丢的是采样密度而不是
插值精度；采样密度的影响见 §5。

## 6. H3 与 hybrid 的逐项差

3ch 前向（均值，dB）：

| 量 | H3 | H3 无 EGN | paper | integral |
|---|---:|---:|---:|---:|
| SPM | −55.567 | −54.835 | −55.018 | −54.951 |
| XPM | −60.365 | −60.551 | −60.739 | −60.741 |
| NLI-SNR | 24.329 | 23.807 | 23.991 | 23.938 |

- EGN 把 SPM 降 0.73 dB（`rho_CUT=0.845`）、把 XPM 升 0.19 dB
  （`rho_nch=1.044`），净 SNR +0.52 dB。
- 关掉 EGN 后，H3 的 SPM 比 paper 高 0.18 dB、XPM 也高 0.19 dB（两项 NLI
  都更大），净 −0.184 dB：PCFM 核 + 拟合比 Buglia 闭式略悲观。
- `paper` 与 `integral` 只差 0.05 dB（前向），说明 Buglia 的 5 参数剖面
  拟合不是差异来源。

3ch 无泵 / 5ch 前向的形态相同：H3 的 SPM 比 paper 低 0.49–0.59 dB
（= EGN 的 −0.73 dB + 核公式的 +0.14…+0.24 dB），XPM 高 0.19–0.37 dB；
关掉 EGN 后 SPM 反而高 0.14–0.24 dB。

### 6.1 归因预算（3ch 前向）

| 项 | ΔSNR (dB) | 说明 |
|---|---:|---|
| EGN 修正 | **+0.522** | H3 默认 `egn=True`；hybrid paper 不做 EGN |
| Buglia vs PCFM 核公式 | **−0.138** | 由同核对照扣除 EGN 后的残差 |
| H3 剖面路径（ODE 24 vs 12 + 拟合网格） | **−0.046** | H3 − hybrid_pcfm |
| 合计 | **+0.338** | H3 − paper |

5ch 前向同理：`+0.444 − 0.129 − 0.048 = +0.267`。
1ch 前向：`+0.732 − 0.142 − 0.044 = +0.546`。

## 7. 是否修改默认

**不修改。** 理由：

1. 拟合项不是主因：全场景界 0.082 dB，前向 ≤0.025 dB，小于
   EGN（0.40–0.73 dB）和 Buglia-vs-PCFM 核差（0.13–0.14 dB）。
2. 提高默认 `poly_degree` / `spp_steps` 会改变无泵默认结果，破坏模型契约
   “无泵时与同选项 H3 PCFM 逐位相同”（也是现有回归测试的硬门槛），
   而收益只有 0.08 dB 量级。
3. 真正的 0.3 dB 差是**口径差**：H3 的默认配置含 EGN，paper 路径不含。
   要 apples-to-apples 比较，应显式 `egn=False` 或给 paper 路径加 EGN，
   而不是改拟合路径。
4. 负结果保留：`(3,12)` 在无泵/后向的 +0.04…+0.08 dB 乐观已写进
   JSON 与本文；这是一个已知的、小于其他误差项的数值代价。

## 8. 回归测试

`tests/test_pcfm_h3_raman.py` 新增两个测试（同一审计配置，
3ch、100 km、50 GBd、1 mW/pol、1450 nm 0.2 W 前向）：

- `test_forward_three_channel_h3_minus_paper_gap_is_pinned`
  断言 `H3 − paper = 0.34 ± 0.05 dB`。任何拟合/核路径漂移超出该带即失败。
- `test_forward_gap_is_dominated_by_egn_not_by_the_polynomial_fit`
  断言 `|(9,96) − (3,12)| < 0.05 dB`、`EGN 贡献 > 0.3 dB`、
  `|前向专属超额| < 0.1 dB`。

原有的无泵逐位一致测试（`test_no_pump_is_bit_identical_to_h3_pcfm`）
保持不变并通过。

## 9. 边界与未决

- 本审计只覆盖**单跨**。多跨时 H3 的 `span_coherence` 会从 `pcfm`
  切到 `incoherent`（泵浦链路），那是一个独立的跨间口径差，不能用本文
  的 0.3 dB 预算外推。
- 只覆盖 1 mW/pol。发射功率升高会改变 `spp_steps="auto"`（>0 dBm 用 32）
  和泵浦耗尽程度；交接表的绝对数值来自不同取数细节，本文只对齐差值。
- `test_forward_gap_is_dominated_by_egn_not_by_the_polynomial_fit`
  里的 0.34 dB 是本文测得的固定值；若未来有意修改 EGN 或核公式，需要
  同步更新该值与本文预算表。
- 直接二维积分基准的梯形离散误差约 1e-3（相对 `K_SCI`），不影响
  0.5% 量级的拟合结论。
